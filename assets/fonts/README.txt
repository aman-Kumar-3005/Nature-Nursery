# Fonts Directory

Google Fonts are linked via CDN in the HTML heads for optimal browser caching:
- `Playfair Display` (Serif editorial headers)
- `Plus Jakarta Sans` (Crisp legible UI & body font)

If you prefer self-hosting WOFF2 web fonts on Hostinger, place the font files in this folder and reference them via `@font-face` in `assets/css/style.css`.
