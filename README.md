## 3. Hostinger Deployment Instructions (1-Click Ready)

1. Log into your **Hostinger hPanel**.
2. Navigate to **Websites** -> Select `naturenursery.in` -> Open **File Manager**.
3. Go inside the **`public_html/`** folder.
4. If there is a default `default.php` or placeholder page, delete it or move it to a backup folder.
5. Select all files and folders inside `d:\Nature Nursery\` (or zip them into `nature-nursery.zip` and upload).
6. Extract directly inside `public_html/` so that `index.html` sits immediately at `public_html/index.html`.
7. Test the live URL in your browser:
   - Check SSL certificate (Hostinger hPanel -> Security -> SSL: Active).
   - Test clicking phone number: triggers dialer with `091655 85858`.
   - Test clicking WhatsApp button: opens `https://wa.me/919165585858` with pre-filled botanical inquiry.
